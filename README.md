## What this is

**Open Privacy** is decision-oriented, not a long dump of every option.

For each category you get:

1. **One primary tool**
2. **One alternative per concrete catch** of that primary (OS gap, payment, region, skill, product surface, etc.)
3. **A local / self-hosted open-source path** when one exists

Research inputs included public catalogs such as [pluja/awesome-privacy](https://github.com/pluja/awesome-privacy), [Privacy Guides](https://www.privacyguides.org/en/tools/), and [AlternativeTo](https://alternativeto.net/), plus official install pages for each primary tool.

## How to use

1. Pick the category you need.
2. Install the **primary** unless a catch applies.
3. If a catch applies, use the **one alternative** listed for that catch.
4. If you want maximum control, use the **local open-source path**.
