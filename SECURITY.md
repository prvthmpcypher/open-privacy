# Security Policy

> **Open Privacy** · v1.0 · August 2026 · Poorvith M P

## Reporting a vulnerability or compromised tool

I take the security and integrity of these recommendations seriously. If you find a security flaw in this repository or discover that an upstream tool recommended here has been compromised, backdoored, or secretly acquired, please report it immediately.

### How to report

- **Email**: Send details directly to `prvthmp@gmail.com` with the subject `[Open Privacy Security] <Issue Summary>`.
- **GitHub Security Advisories**: You can also open a private vulnerability report directly through the GitHub repository's **Security** tab.

Please include:
1. The tool or repository file affected.
2. A clear description of the vulnerability, compromise, or threat.
3. Relevant upstream links, CVE numbers, commit hashes, or security advisories.

### Response expectations

- I will acknowledge receipt of your report within **24–48 hours**.
- If a recommended tool has a critical zero-day, confirmed supply-chain backdoor, or verified telemetry breach, I will update the repository and warn users within **24 hours** of verification.

## Scope

This repository contains curated documentation, install steps, and verified tool links. It does not run a central backend or collect user telemetry.

- **In scope**: Vulnerabilities in repository documentation (e.g. malicious URLs, compromised install scripts, insecure configuration guides), and critical security compromises in primary tool recommendations.
- **Out of scope**: General bugs or feature requests for third-party software (report those directly to the upstream project maintainers).
